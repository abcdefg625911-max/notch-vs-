# Notch VS 古振兴

一个由 AI 辅助制作的 Minecraft Fabric 恶搞模组，主要围绕 Notch 与古振兴制作的娱乐向内容。

> 本项目为非官方、娱乐向作品，与 Mojang Studios、Microsoft 及模组中涉及的人物没有官方关联。

## 模组内容

- 加入 Notch 与古振兴相关角色与内容
- 包含自定义模型、动作与互动
- 包含娱乐向物品、音乐/唱片及交易内容
- 以整活和恶搞体验为主

## 下载

正式版本会放在本仓库的 **Releases** 页面中。

进入 Releases 后，下载对应版本的 `.jar` 文件即可。

## 安装方法

1. 安装与模组版本匹配的 Minecraft Java Edition。
2. 安装对应版本的 Fabric Loader。
3. 下载本模组的 `.jar` 文件。
4. 将文件放入 Minecraft 的 `.minecraft/mods` 文件夹。
5. 启动 Fabric 游戏配置即可。

如某个版本还需要其他依赖，请以对应 Release 的说明为准。

## 注意事项

- 本模组主要用于娱乐。
- 不建议将不同 Minecraft 版本的模组文件混用。
- 如果更新新版本，请先备份存档。
- 如遇到问题，可以在仓库的 Issues 中反馈。

## 关于

这是一个个人娱乐项目，部分开发工作由 AI 辅助完成。
